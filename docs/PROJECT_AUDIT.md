## 4. Existing API contract

`docs/CONTRACT.md` v1. Status lifecycle today:
`QUEUED (phone) → RELAYED → DELIVERED → ACKNOWLEDGED → RESOLVED`.

Gap vs the TrackMate brief: the brief adds `TRANSMITTED` and `DISPATCHED`, and
requires **communication state to be separate from incident state**. Today one
`status` field holds both. Changing this is a contract change; see
ARCHITECTURE.md §5 for the proposed backward-compatible v2. **Not changed yet.**

## 8. What the new features need (not implemented)

### Fitness / Health Connect
- A native Health Connect module for React Native (community library; evaluate maintenance, Expo config plugin support, SDK 58 compatibility). The project already uses a development build, so native modules are possible.
- Android manifest permissions per data type, a permissions-rationale screen, and a privacy policy link (required by Health Connect / Play policy — **verify current requirements**).
- Google Play health-data declaration before release.
- Abstraction: `FitnessProvider` → `HealthConnectAdapter`, `FitnessSyncService`, `ActivityRepository`, `FitnessPermissionManager`.
- Backend: `FitnessConnection`, `FitnessActivity` tables, stored apart from SOS data; health data never sent to responders by default.
- Decide what (if anything) syncs to the server vs stays on device (data minimisation).

### Co-tracker discovery
- Accounts and auth (none exist today).
- Backend: `CoTrackerProfile`, `ConnectionRequest`, `GroupJourney`, `GroupMembership`, block/report/moderation tables, rate limits.
- Location privacy: coarse/region-level discovery only; live location only after explicit, revocable consent.
- Moderation workflow and an admin surface.
- Messaging (only after connection accepted) — needs a decision: build vs use a provider.

### Plans and pricing
- Backend: `SubscriptionPlan`, `PlanFeature`, `UserSubscription`, `BillingPeriod`, `PaymentTransaction`, `SubscriptionEntitlement`, admin-editable, per market/currency.
- Server-side entitlement checks; SOS exempt from all entitlement gates.
- Payment research: Google Play Billing rules for in-app digital subscriptions (and India's billing options), RBI recurring-payment rules, refunds/cancellation. **Needs policy and legal review.**
- Pricing page (mobile + web), billing history, plan state.
